# AppLock downloads

Downloads for **AppLock**, a private app locker for Android. This repository contains only the finished app.
Download the newest `AppLock-vX.Y.Z.apk` from the file list above (open the file, then **Download raw file**). `latest.json` names the current version.

| File | For |
| --- | --- |
| `AppLock-vX.Y.Z.apk` | Android 10 and newer |

## Installing

Open the APK on your phone. Allow "Install unknown apps" when asked. If Play Protect warns, choose **More details, Install anyway**.

Once installed, AppLock can update itself: **Settings, Updates, Check for updates**.
